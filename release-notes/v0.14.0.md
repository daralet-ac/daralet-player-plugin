## Hide game UI

- **Hide the game's UI for screenshots.** A new **Hide game UI** section on the Config tab hides all of the game's
  in-world UI with one key (F1 to start), and the same key brings it back. **Hide game UI** there hides it straight
  away, and `/dap hideui` and `/dap showui` do it from chat.
- **Pick your own key** in the same section: click it and press a key, Escape to cancel, right-click to clear it. It's
  kept in your settings profile. Ctrl and Shift don't help here: the game ignores them on its own keys, so pick a key
  the game doesn't use.
- **The plugin's windows hide too,** each keeping its own setting, so they come back as they were. Tick **Keep plugin
  windows** to hide only the game's UI. Other plugins' windows and Decal's bar stay.
- **Never left hidden.** Logging out clears it, and the UI comes back if the plugin is closed or reloaded.

## Loot marks

- **Any colour.** A rule's highlight can be any colour you like, from a colour picker, or one of the ready-made swatches
  beside it: gold, silver, bronze, green, blue, purple, red, orange, pink, cyan and white. Rules you already have keep
  their colours.
- **Icons get their own colour,** with the same picker. Without one, an icon takes the highlight's colour, or gold.
- **More icons:** the grade letters S, A, B, C, D, E and F, and Square, Heart, Plus, Cross, Check mark and Up arrow.
  The Icon list is now a grid showing each one in the colour it will have.
- **The $ icon** no longer reads as an S: its bar now runs clear of the letter at both ends.
- **A new Example Loot Profile,** and **Example Loot Profile (colorless)**, the same rules marked white, gray and black
  instead of gold, silver and bronze. The Loot tab's **Example (colorless)** button adds it again.

## Carried packs

- **Tags and Icon for the packs you carry.** Your side packs now have the same **Tags** and **Icon** drop-downs as the
  bank's packs, in the Carried tab, the Inventory window's Retail view and the Bank view with **Show my packs** on. Tags
  on carried packs need the server's latest update; icons already work.
