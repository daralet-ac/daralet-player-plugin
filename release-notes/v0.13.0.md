## Client UI Override

- **Every switch that puts the plugin's windows in place of the game's, in one place.** A new **Client UI Override**
  section on the Config tab holds the four toolbar buttons (Inventory, Quests, Map and Character) and **Bank window**
  and **Loot window**, which used to be spread across each window's own settings.
- **Enable all and Disable all** switch all six at once. Enable all asks first when it's about to turn on Bank window
  or Loot window, as their own checkboxes do, and Disable all says what changes when either was on. On a server too old
  for Bank window or Loot window, those two stay off.
- **Your choices carry over:** whatever you had ticked before is still ticked, just found on the Config tab now. The
  Inventory and Loot tabs' settings say where the switches went.
