## Daralet tells you when there's a new version

From this version on, you don't have to check the releases page yourself.

- **A line in chat** when you log in, if a newer version of Daralet is out.
- **An Update button** at the top of the `/dap` window, next to your character's name, while there is one. Click it for
  the new version's download page, then close the game and the Decal agent and run its installer. Your settings and
  loot profiles are kept.

Daralet checks once each time it starts. It only tells you: nothing is downloaded or installed without you.

To get this version, download **Daralet-Setup-0.5.1.exe** below and run it with the game and the Decal agent closed.
After that, Daralet tells you about every new version itself.
