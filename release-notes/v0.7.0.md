## Daralet is now Daralet Toolkit

Same plugin, new name. The window, Decal's list of plugins, chat lines and the installer all say **Daralet Toolkit** now,
and the file is `DaraletToolkit.dll`.

- **Upgrading with the installer:** run **DaraletToolkit-Setup-0.7.0.exe** below with the game and the Decal agent
  closed. It replaces the old `Daralet.dll` in the same folder and keeps it ticked in Decal.
- **Upgrading by hand:** put `DaraletToolkit.dll` in the same folder as the old one, then in the Decal agent click
  **Add**, **Browse** and pick it. Decal knows it as the same plugin, so it takes the old entry's place. Then delete
  `Daralet.dll`.
- **Your settings and loot profiles come with you.** They now live in `Documents\Decal Plugins\Daralet Toolkit`, and the
  plugin moves them there from the old `Daralet` folder the first time it starts.
- **The project moved** to [github.com/daralet-ac/daralet-toolkit](https://github.com/daralet-ac/daralet-toolkit). Old
  links still work.
- `/dap` still opens the window.

## Also

- **Tidier settings.** Each tab's settings sit under a **Settings** header that starts closed, laid out like the Hotbars
  page: a section for each window, labels with their controls lined up, and rows that wrap to fit. On a wide window,
  World, Target and Inventory show their sections side by side.
- **Every floating window's settings look the same:** Enabled, Only when needed, Locked and Reset position, then Size and
  Background. "Shown" is now "Enabled", on the windows and the hotbars.
- **The Bank window's** size and background can now be set from the Inventory tab.
- **World:** the Text slider and the map data status moved into Settings.
- **The map loads once, when you log in,** and the World tab and the Map window share it, so opening either one no
  longer waits for it.
